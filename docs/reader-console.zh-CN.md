# 离线案例演示台

[打开案例展示页（2026-10-20）](https://liutong-luban-demo.netlify.app/)。公开展示提供八个录制回合、三路相机画面、任务图、Planner 与 Verifier 事件。选择案例后点击开始，可暂停、拖动进度和查看节点详情。此入口不连接模型服务，也不执行新的机器人任务。

控制台使用独立的 liutong-luban-demo.netlify.app 域名，打开首页即可回放。项目展示首页链接返回 liutong-luban-project.netlify.app，旧 offline/expert/reader 路径仍可跳转到当前展示入口。中文展示名称为六通智能体，英文项目名为 Luban。

任务图使用录像帧对应的展示时间轴。环境成功终帧可将记录延迟的目标显示为随任务达成，原始节点状态与执行记录仍保留。控制台是独立维护的前端，框架安装包范围保持不变。自行执行任务请按[安装](installation.zh-CN.md)、[配置](configuration.zh-CN.md)与[回合指南](episodes.zh-CN.md)准备资源。
